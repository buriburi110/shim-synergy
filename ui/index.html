직접 연결을 요청한 컴퓨터인지 확인해 주세요.

처음 연결하는 방법

  1. 같은 공유기에 연결하세요.

    맥과 윈도우를 같은 Wi-Fi 또는 유선 네트워크에 연결합니다.

  2. 주 컴퓨터에서 ‘연결 받기’를 누르세요.

    기본은 맥이 주 컴퓨터입니다. 연결 설정에서 언제든 바꿀 수 있어요.

  3. 다른 컴퓨터에서 주 컴퓨터의 IP를 입력하세요.

    두 화면의 확인 번호가 같은지 보고, 주 컴퓨터에서 연결을 허용합니다.

  4. 마우스를 화면 끝으로 옮겨 보세요.

    맥은 시스템 설정의 손쉬운 사용과 입력 모니터링에서, 앱 안에 포함된 Deskflow에 권한을 허용해야 합니다. 권한 변경 후 연결을 다시 시작하세요.

윈도우의 관리자 권한 창과 로그인 화면은 이 버전에서 조작할 수 없습니다. 로컬 키보드·마우스는 계속 사용할 수 있습니다.
