시너지 0.1.1 — 검증 결과

공개 저장소: https://github.com/buriburi110/shim-synergy
설치 파일: https://github.com/buriburi110/shim-synergy/releases/tag/v0.1.1

소스 태그: v0.1.1

수정 및 확인 완료
- 연결 전 창 닫기 후 트레이 재열기, 창 재생성, 최소화 상태의 재실행 복구 수정.
- 트레이의 연결 중지가 입력 공유 엔진과 최초 연결 승인 대기를 함께 종료하도록 수정.
- 승인 대기의 종료·만료를 화면에 반영하고, 요청 거절 후 대기 표시는 유지하도록 수정.
- 자동 단위·TLS 테스트 12개 통과.
- 실제 Electron 창 동작 시험을 로컬 Windows 및 GitHub의 Windows·macOS·Linux 호스트에서 통과.
  각 시험은 임시 프로필에서 실행하며 입력 공유를 시작하지 않음.
- Windows x64 MSI와 macOS arm64·x64 PKG 자동 빌드 및 공개 릴리스 업로드 성공.
- GitHub에서 내려받은 MSI로 이 Windows PC의 0.1.0 → 0.1.1 업데이트 설치 성공(종료 코드 0).
- 설치된 앱 버전 0.1.1.0, 한국어 창 실행, MSI 언어 코드 1042 확인.
- 포함된 입력 공유 엔진은 기존과 같은 Deskflow 1.27.0이며 설치 경로에서 버전 확인.
- 세 설치 파일의 SHA-256이 GitHub Release digest와 일치.
  배포/SHA256-installers-0.1.1.json 및 동일한 이름의 릴리스 첨부 파일에 기록.

남은 확인 항목
- 실제 Mac에서 PKG 설치와 손쉬운 사용·입력 모니터링 권한 허용.
- 실제 Mac↔Windows의 화면 경계 이동·클릭·한글 입력·클립보드 왕복.
- 실제 두 컴퓨터에서 끊김 후 재연결, 단축키 변환, 좌우·상하 배치 확인.

사용자는 현재 Mac을 사용할 수 없다고 답함. 위 실기기 항목은 미확인 상태임.
macOS 빌드와 창 동작 시험은 두 컴퓨터 사이의 실제 입력 공유를 증명하지 않음.
개발자 서명과 Apple 공증이 없는 초기 시험 버전이며, Symless의 공식 제품이 아님.

확인 완료
- 자동 테스트 11개 통과.
- 공개 GitHub 저장소에 소스·한국어 안내·원본 분해 분석·화면 이미지 게시.
- Windows x64 MSI, Apple Silicon macOS PKG, Intel macOS PKG 모두 빌드 및 릴리스 업로드.
- Windows 한국어 MSI 실제 설치 성공. 한국어 설치 언어 코드 1042 확인.
- 설치된 Windows 앱 실행 및 포함된 Deskflow 1.27.0 엔진 버전 확인.
- 실제 네이티브 엔진 두 개의 상호 지문 검증, TLS 1.3, 입력 프로토콜 핸드셰이크 통과.
  이 시험은 같은 Windows의 루프백 연결이며 화면 링크를 비웠고 입력을 생성하지 않았음.
- macOS PKG 두 개의 내부 Payload를 읽어 app.asar와 deskflow-core가 실제로 포함됨을 확인.
  Apple Silicon 엔진은 arm64, Intel 엔진은 x64 Mach-O CPU 값으로 확인.
- 내려받은 세 설치 파일 SHA-256이 GitHub Release의 digest와 일치.
  자세한 값은 배포/설치파일-검증.json에 기록.

아직 확인하지 못한 항목
- 실제 Mac에서 PKG 설치와 손쉬운 사용·입력 모니터링 권한 허용.
- 실제 Mac↔Windows의 화면 경계 이동·클릭·한글 입력·클립보드 왕복.
- 실제 두 컴퓨터에서 끊김 후 재연결, 단축키 변환, 좌우·상하 배치 확인.

사용자가 현재 Mac을 사용할 수 없어 실기기 확인을 기다리고 있음.
위 항목이 통과하기 전에는 전체 목표가 완료되었다고 판단하지 않음.
개발자 서명과 Apple 공증이 없는 초기 시험 버전이며, Symless의 공식 제품이 아님.
