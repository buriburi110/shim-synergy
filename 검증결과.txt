확인 완료
- 자동 테스트 11개 통과.
- 공개 GitHub 저장소에 소스·한국어 안내·원본 분해 분석·화면 이미지 게시.
- Windows x64 MSI, Apple Silicon macOS PKG, Intel macOS PKG 모두 빌드 및 릴리스 업로드.
- Windows 한국어 MSI 실제 설치 성공. 한국어 설치 언어 코드 1042 확인.
- 설치된 Windows 앱 실행 및 포함된 Deskflow 1.27.0 엔진 버전 확인.
- 실제 네이티브 엔진 두 개의 상호 지문 검증, TLS 1.3, 입력 프로토콜 핸드셰이크 통과.
  이 시험은 같은 Windows의 루프백 연결이며 화면 링크를 비웠고 입력을 생성하지 않았음.
- macOS PKG 두 개의 내부 Payload를 읽어 app.asar와 deskflow-core가 실제로 포함됨을 확인.
  Apple Silicon 엔진은 arm64, Intel 엔진은 x64 Mach-O CPU 값으로 확인.
- 내려받은 세 설치 파일 SHA-256이 GitHub Release의 digest와 일치.
  자세한 값은 배포/설치파일-검증.json에 기록.

아직 확인하지 못한 항목
- 실제 Mac에서 PKG 설치와 손쉬운 사용·입력 모니터링 권한 허용.
- 실제 Mac↔Windows의 화면 경계 이동·클릭·한글 입력·클립보드 왕복.
- 실제 두 컴퓨터에서 끊김 후 재연결, 단축키 변환, 좌우·상하 배치 확인.

사용자가 현재 Mac을 사용할 수 없어 실기기 확인을 기다리고 있음.
위 항목이 통과하기 전에는 전체 목표가 완료되었다고 판단하지 않음.
개발자 서명과 Apple 공증이 없는 초기 시험 버전이며, Symless의 공식 제품이 아님.
